Stable fluids: the underlying equations

This is a web implementation of Jos Stam's stable fluid simulation which produces colourful smoke that you can interact with. The document I followed didn't go into too much detail on the maths behind the simulation so I was interested to work backwards and reconstruct the maths from the implementation.

Ripple simulations

I have created a few simulations which attempt to produce an accurate depiction of ripples on the surface of a liquid. This one is the most realistic of the bunch and is a WebGPU finite difference simulation of the wave equations in 2 dimensions using GPU shaders for both the update rules and the rendering.

Parallelised Julia sets

Each point in a Julia set or the Mandelbrot set can be computed independently of the others. This makes them fantastic candidates for parallelisation. This is a C++ experiment comparing different levels of parallelisation, as well as a GPU web demo.

Online Concertina

This was a little demo of a concertina. It works well if you have muscle memory for the button locations on a concertina but chords don't always sound due to most keyboards having a low key rollover.

Advent of Code Solutions

I use the AOC problems as a chance to acquaint myself with new languages. Most recently, I completed the 2021 calendar of problems in Java.
