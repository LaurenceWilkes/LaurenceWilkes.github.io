Advent of Code

Overview

Advent of Code is a yearly coding challenge that releases each day in December leading up to Christmas. (From 2025 there are only 12 challenge days.) The challenges cover a broad range of language-independent skills such as parsing, data structures, graph algorithms, optimisation, and simulation.

The years I have completed are:

  1. 2019

    PYTHON
    Sample Problem:

    Day 22 – Slam Shuffle

    This was a rather nice application of modular arithmetic. The solution collects all the operations performed on the deck into one big operation and then inverts it for part 2.

    View solution

  2. 2020

    C++
    Sample Problem:

    Day 23 – Crab Cups

    Another problem with modular themes which scales beyond a naïve simulation for the second part. Simulating with an array or vector is too slow and so a linked list is required. As the values are integers, we store this in an array of nextCup values.

    View solution

  3. 2021

    JAVA
    Sample Problem:

    Day 18 – Snailfish

    This involved the recursive arithmetic of these nested "Snailfish numbers". The problem was a good chance to use Java's inheritance and other OO features.

    View solution

  4. 2023

    JULIA
    Sample Problem:

    Day 24 – Never Tell Me The Odds

    Predicting the trajectory of hailstones in 3D. Part 2 involves finding the trajectory of a rock which will collide with all the hailstones. A nice problem involving some integer Computational Geometry and solving a least squares problem (though my solver is very numerically dubious).

    View solution

  5. 2024

    C++
    Sample Problem:

    Day 21 – Keypad Conundrum

    The idea was to find the shortest amount of button presses on many keypads which recursively controlled each other. This solution isn't the most refined or optimised but this was one of the more enjoyable problems with a nice opportunity for some memoisation.

    View solution

  6. 2025

    RUST
    Sample Problem:

    Day 8 – Playground

    We are tasked with connecting junction boxes located in 3D space starting with the closest together. The problem ends up being a version of Kruskal's algorithm for the minimum spanning forest of a graph.
